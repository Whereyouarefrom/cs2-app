# CS2 Case Simulator — Telegram Mini App

Фановый симулятор открытия кейсов CS2/CS:GO без реального вывода денег и скинов.
Валюта — виртуальные **Кристаллики 💎**.

## Структура проекта

- `config.py` — конфигурация (токен бота, admin ID, username бота, Adsgram block ID)
- `database.py` — модели SQLAlchemy (Users, Inventory, PromoCodes, Giveaways)
- `bot.py` — Telegram-бот на Aiogram 3 (запуск Mini App, VIP через Stars, админ-команды)
- `main.py` — FastAPI backend (экономика/шансы кейсов, открытие, инвентарь, мини-игры)
- `cases_data.py` — база кейсов (сид из 3 проверенных кейсов с реальными Steam CDN ссылками)
- `sync_cases.py` — скрипт, который подтягивает ПОЛНЫЙ актуальный каталог всех кейсов CS:GO/CS2 из официального Items API
- `index.html`, `style.css`, `app.js` — фронтенд Mini App (кейсы, инвентарь, профиль, мини-игры Upgrade/Crash)

## Что реализовано (Часть 1)

- **Реальные изображения** — все иконки кейсов и скинов подгружаются по прямым HTTPS-ссылкам Steam CDN (`community.akamai.steamstatic.com`), полученным из официального открытого CS2 Items API. Заглушек/фейковых ссылок нет.
- **Полный каталог кейсов** — `cases_data.py` идёт с 3 проверенными реальными кейсами "из коробки"; запусти `python sync_cases.py` один раз, чтобы подтянуть ВСЕ кейсы CS:GO/CS2 напрямую из актуальных данных игры (без правки кода).
- **Telegram-профиль** — аватар и имя подтягиваются из `window.Telegram.WebApp.initDataUnsafe.user` (`photo_url`, `first_name`).
- **Реферальная ссылка** — username бота отдаётся бэкендом (`GET /api/app-config`), подставь свой в `config.py -> BOT_USERNAME`.
- **Локализация (i18n)** — Русский / English / Українська, переключатель в Профиле, сохраняется и на устройстве, и на сервере (в профиле пользователя).
- **Звук** — синтезированные эффекты через Web Audio API (щелчки вращения, фиксация предмета, победные фанфары для Тайного/★, клики по кнопкам), переключатель Вкл/Выкл в шапке и в Профиле.
- **Просмотр содержимого кейса** — при клике на кейс открывается вертикальный скроллируемый список ВСЕХ предметов внутри, от Ножей до Ширпотреба.
- **StatTrak™ и качество** — 10% шанс StatTrak™ (кроме перчаток), каждому предмету присваивается качество FN/MW/FT/WW/BS; цена в 💎 зависит от редкости × качества × StatTrak™.
- **Умные динамические шансы** (`build_dynamic_weights` в `main.py`):
  - 🟥 Тайное / ★ Особо редкое (ножи/перчатки) — фиксированно 1-2% суммарно;
  - 🟪 Запрещённое — ~15-18%; 🟖 Засекреченное — ~5-6%;
  - если в кейсе нет Ширпотреба/Промышленного — остаток (~75-80%) уходит Армейскому;
  - если есть — Ширпотреб/Промышленное/Армейское делят между собой оставшийся пул (~70-75%+).

## Установка

```bash
pip install -r requirements.txt
```

Заполни `config.py`:
- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_ID` — твой Telegram ID
- `BOT_USERNAME` — username бота без `@` (для реферальных ссылок)
- `ADSGRAM_BLOCK_ID` — ID блока с adsgram.ai

(Опционально) подтяни полный каталог кейсов:
```bash
python sync_cases.py
```

## Запуск локально

Backend (FastAPI):
```bash
python main.py
```

Telegram-бот:
```bash
python bot.py
```

Фронтенд — задеплой `index.html`/`style.css`/`app.js` на любой статический хостинг (Vercel, GitHub Pages, Render) и укажи URL:
- в `WEBAPP_URL` внутри `config.py`
- в `API_BASE` внутри `app.js` (адрес твоего задеплоенного backend + `/api`)

## Админ-команды бота

- `/stats` — общая статистика проекта
- `/give_balance <telegram_id> <amount>` — выдать виртуальный баланс
- `/addpromo <code> <type:value> <max_activations>` — создать промокод
- `/user_info <telegram_id>` — информация о пользователе

## API-эндпоинты (FastAPI)

- `GET /api/app-config` — конфиг для фронтенда (username бота, adsgram block id, реф-бонусы)
- `GET /api/cases` — список кейсов с полным содержимым
- `POST /api/open-case` — открыть кейс (поддерживает `count`: 1, 2, 3, 4, 5 или 10 открытий за раз)
- `POST /api/sell-skin` — продать один скин
- `POST /api/sell-multiple` — распылить несколько выбранных предметов в Кристаллы за одну транзакцию
- `POST /api/promo` — активировать промокод
- `GET /api/user/profile` — профиль пользователя
- `POST /api/user/settings` — сохранить язык/звук
- `GET /api/inventory` — инвентарь пользователя
- `POST /api/ad-reward` — награда за просмотр rewarded-рекламы
- `POST /api/minigames/upgrade` — мини-игра Upgrade
- `POST /api/minigames/crash` — мини-игра Crash/Dice (используется во вкладке «Мини-игры» как 🚀 Ракета)
- `GET /api/bonus-status` — сколько секунд осталось до следующего бесплатного бонуса
- `POST /api/bonus-claim` — забрать бонус 💎 2000 (раз в 60 секунд)
- `POST /api/minigames/wheel` — 🎡 Колесо (ставка → случайный множитель)
- `POST /api/minigames/mines/start|reveal|cashout` — 💣 Минёр (сессионная игра, поле 5×5)
- `POST /api/minigames/tower/start|pick|cashout` — 🗼 Башня (8 уровней, 3 плитки, 1 бомба)
- `POST /api/minigames/ladder/start|pick|cashout` — 🪜 Лесенка (5 уровней, 2 плитки, 1 бомба)

## Что реализовано (Часть 4)

- **Adsgram SDK подключён корректно** — раньше в `index.html` отсутствовал сам `<script>` с SDK, поэтому `window.Adsgram` всегда был `undefined` и реклама всегда уходила в тестовый фолбэк. Теперь SDK подключается в `<head>`, контроллер инициализируется один раз (`Adsgram.init` не дёргается на каждый клик) и переиспользуется как для rewarded-видео, так и для interstitial-показов.
- **Кнопка «Бонус 💎 2000»** на вкладке «Заработать» — бесплатный бонус раз в 60 секунд, cooldown считается на бэкенде (`/api/bonus-status`, `/api/bonus-claim`), поэтому таймер не сбрасывается при перезагрузке страницы.
- **Вкладка «Мини-игры» переработана в контейнер** — сетка из 6 иконок (Ракета 🚀, Улучшитель 🔺, Колесо 🎡, Минёр 💣, Башня 🗼, Лесенка 🪜), каждая открывает единый полноэкранный контейнер (`#game-screen`), в который JS динамически подставляет разметку нужной игры — без дублирования HTML на каждую игру.
- **Единый баланс** — все мини-игры списывают ставку и зачисляют выигрыш напрямую в `User.balance` на бэкенде; фронтенд синхронизирует отображаемый баланс в шапке и в самом игровом контейнере после каждого действия.
- Мини-игры Минёр/Башня/Лесенка — сессионные (состояние раунда хранится на бэкенде в памяти по `telegram_id`); при выходе с экрана мини-игры активный раунд автоматически обналичивается, чтобы ставка не "терялась" молча.

## Важно

- Все иконки грузятся по прямым ссылкам Steam CDN, локальные файлы изображений не используются.
- VIP-статус (через Telegram Stars) даёт только косметику и отключение рекламы — не влияет на игровые шансы.
- Виртуальная валюта (Кристаллики 💎) пополняется через рекламу, рефералов и промокоды.
- Проект не связан с реальным выводом денег или предметов — это развлекательный симулятор.

## ⚠️ Безопасность

В `config.py` в этом проекте уже был указан реальный `BOT_TOKEN` — это чувствительный секрет.
Рекомендуется:
1. Немедленно перевыпустить токен через @BotFather (`/revoke`), если он уже где-то засветился.
2. Не коммитить `config.py` с реальными значениями в публичный репозиторий — вынеси секреты в переменные окружения.
